# Search indexing

The public download page has a canonical URL, descriptive metadata, share image, robots.txt and sitemap.xml. Account screens are marked noindex. These files help discovery; they do not guarantee ranking or inclusion.

Google Search Console's URL-prefix property is `https://dhun-cloud.vercel.app/`, under the owner's Google account. The Google-provided ownership file is `public/googled80d063f1b4ddd36.html`. Keep this file deployed to retain ownership verification.

Submit `https://dhun-cloud.vercel.app/sitemap.xml` in Search Console's Sitemaps screen. Use URL Inspection on `/download` to request indexing. Search Console's indexing and performance reports can take time to populate; submission does not guarantee indexing.

A custom domain can be added later; update canonicals, sitemap, robots and share URLs together when doing so.
