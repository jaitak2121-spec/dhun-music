# Source provenance and third-party credits

Dhun is a modified version of [DollBloom](https://github.com/DominatorStufs/DollBloom), which is itself derived from BitChord. The initial imported source is commit `49381fcfd49fb739046584460fbf8c57b0c732d1`. Upstream history and original copyright notices are retained.

The project is distributed under GNU GPL version 3. Individual third-party files retain their own notices, including AGPL-origin Automix code, Apache-licensed audio components and other attributed components. Those notices are not superseded by Dhun branding. See [LICENSE](LICENSE), source-file headers and the [archived upstream README](docs/UPSTREAM_README.md).

Modifications for Dhun include the application identity and namespace, monochrome visual system, optional colour palettes, logo assets, home branding, settings controls and update repository configuration. The Dhun commits follow the imported upstream history.

The original project's signing files and publishing workflows are retained as historical reference. They must not be used as Dhun signing credentials or represented as Dhun-operated services.

The earbud-and-waveform logo was reconstructed from the owner's supplied reference. The approved raster preview and its scalable implementation are in `assets/brand/`.
